# Pre-Publish Checklist

**Any "no" → fix or discard. Never post "close enough".**

## Before you prompt
- [ ] Placement & aspect ratio decided
- [ ] ONE hero named
- [ ] Reading order written (hero → headline → support → CTA)
- [ ] Copy written in one voice; headline ≤ 6 words; total ≤ ~25 words
- [ ] ONE typeface family, ≤ 3 sizes
- [ ] ≤ 3 colours with hex and roles
- [ ] Lighting setup named
- [ ] ONE pattern-break chosen (or none, for calm/premium)
- [ ] Named style reference (not "modern/clean")
- [ ] Ban list included

## 1-second scan (view at phone thumbnail size)
- [ ] I know what it is in 1 second
- [ ] My eye lands on the hero first
- [ ] Headline readable at thumbnail size / from 3 metres for print

## Hierarchy & contrast
- [ ] Headline is clearly 3×+ bigger than body
- [ ] Only one element shouts
- [ ] Text has strong contrast with what's behind it

## Spacing & clutter
- [ ] ≤ ~3 distinct objects
- [ ] 30–50% intentional empty space
- [ ] Margins consistent; nothing accidentally touching edges
- [ ] Related items grouped; one alignment edge

## Slop audit
- [ ] No glow, sparkles, lens flare, particles, steam, neon purple
- [ ] No plastic skin, extra fingers, warped hands, melted objects
- [ ] No garbled background text, fake logos, watermark-like marks
- [ ] Hasn't drifted to the category's stock look
- [ ] A competitor could NOT post this unchanged

## Text (read letter by letter)
- [ ] Every word matches the brief exactly
- [ ] Prices, dates, days, times, phone numbers, names verified — twice
- [ ] No extra words the generator added
- [ ] Story/Status: text out of top/bottom UI zones

## Fit
- [ ] Correct size/ratio for the platform; cropped deliberately
- [ ] Print: upscaled to 300 dpi at final size, 3 mm bleed if the printer asks
- [ ] Consistent with the brand's recent posts (same recipe)
- [ ] Real logo added (not an AI-drawn one)
