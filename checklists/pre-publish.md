# Pre-Publish Checklist

**Any "no" → fix or discard. Never post "close enough".**

## Before you prompt
- [ ] What it is + where it's posted → aspect ratio, size, safe zones locked
- [ ] ONE hero named
- [ ] Reading order written (hero → headline → support → CTA)
- [ ] Copy written in one voice; headline ≤ 6 words; total ≤ ~25 words
- [ ] ONE typeface family, ≤ 3 sizes
- [ ] ≤ 3 colours with hex and roles
- [ ] Lighting setup named
- [ ] ONE pattern-break chosen (or none, for calm/premium)
- [ ] Named style reference (not "modern/clean")
- [ ] Ban list included

## 1-second scan (view at phone thumbnail size)
- [ ] I know what it is in 1 second
- [ ] My eye lands on the hero first
- [ ] Headline readable at thumbnail size / from 3 metres for print

## Hierarchy & contrast
- [ ] Headline is clearly 3×+ bigger than body
- [ ] Only one element shouts
- [ ] Text has strong contrast with what's behind it

## Spacing & clutter
- [ ] ≤ ~3 distinct objects
- [ ] 30–50% intentional empty space
- [ ] Margins consistent; nothing accidentally touching edges
- [ ] Related items grouped; one alignment edge

## Slop audit
- [ ] No glow, sparkles, lens flare, particles, steam, neon purple
- [ ] No plastic skin, extra fingers, warped hands, melted objects
- [ ] No garbled background text, fake logos, watermark-like marks
- [ ] Hasn't drifted to the category's stock look
- [ ] A competitor could NOT post this unchanged

## Human-made audit (would anyone think "AI made this"?)
- [ ] No frosted glass, neon outlines, glow, flares, sparkles, bokeh orbs
- [ ] Not the default navy + cyan "tech" palette (unless it's genuinely the brand)
- [ ] No feature lists, stock icons, filler labels, pointless arrows, fake UI/code
- [ ] Real photo used exactly — no smoothing, face unchanged, pores visible
- [ ] One light direction; background matches the light on the face; no fake rim light
- [ ] Contact shadows, clean hair edges, matching grain and sharpness
- [ ] The 3 most "AI" things named and removed

## Photoshop craft
- [ ] Cut-out edges clean (hair refined, no colour fringe)
- [ ] One global light angle for every shadow, bevel and highlight
- [ ] Every glow / rim light has a source; used on 1–2 elements only
- [ ] Subject graded to match the scene (black level, temperature, grain)
- [ ] Depth: overlap, stacked shadows, defocus on far layers

## Wow
- [ ] One idea you can say in a sentence; 1–3 signature moves, no more
- [ ] Named fonts, max 3 faces, huge type tracked tight
- [ ] Polish: same radii, one shadow recipe, optical alignment, nothing accidental
- [ ] CONTENT LOCK: every listed text and element is present in the result

## Mockups
- [ ] Every screen exactly as captured — zoom in: no garbled or invented UI text
- [ ] Screens brightest and sharpest in the frame, readable at half size
- [ ] Devices unbranded; correct perspective and corner radius; contact shadows
- [ ] Demo data only

## YouTube thumbnail
- [ ] ≤ 3 elements, ≤ 4 words, text doesn't repeat the title
- [ ] Readable at 168×94 (squint test); face 30–40% of height, eyes sharp
- [ ] Bottom-right corner clear (duration stamp)
- [ ] Everything shown is really in the video

## Text (read letter by letter)
- [ ] Every word matches the brief exactly
- [ ] Prices, dates, days, times, phone numbers, names verified — twice
- [ ] No extra words the generator added
- [ ] Story/Status: text out of top/bottom UI zones

## Fit
- [ ] Correct size/ratio for the platform; cropped deliberately
- [ ] Print: upscaled to 300 dpi at final size, 3 mm bleed if the printer asks
- [ ] Consistent with the brand's recent posts (same recipe)
- [ ] Real logo added (not an AI-drawn one)
